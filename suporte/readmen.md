# 🖥️ HelpDesk N1 — Central de Suporte Técnico

Sistema de gerenciamento de chamados desenvolvido em Python e SQLite, com o objetivo de simular o funcionamento de uma Central de Help Desk / Service Desk (Suporte Nível 1).

O projeto foi desenvolvido para aplicar conhecimentos de programação, gerenciamento de banco de dados, registro de incidentes e organização de solicitações de suporte técnico em um ambiente simulado.

---

## 📊 Dashboard

Painel principal do sistema, permitindo visualizar e acompanhar os chamados registrados, facilitando a organização e o controle das solicitações de suporte.

![Dashboard do HelpDesk N1](imagens/dashboard.jpeg)

---

## 🎫 Abertura de Novo Chamado

Interface para registrar novas solicitações de suporte técnico, permitindo informar o título, cliente, categoria e descrição do problema.

![Abertura de Novo Chamado](imagens/novo-chamado.jpeg)

---

## 📋 Acompanhamento de Chamados

Visualização do conjunto de chamados registrados no sistema, demonstrando a organização e o acompanhamento das solicitações de atendimento.

![Detalhes e acompanhamento dos chamados](imagens/detalhe-chamado.jpeg)

---

## ⚙️ Funcionalidades

- Abertura e registro de chamados técnicos.
- Identificação de clientes.
- Classificação de solicitações por categoria.
- Armazenamento persistente utilizando SQLite.
- Consulta e acompanhamento de chamados.
- Organização das informações de atendimento.
- Dashboard para visualização dos chamados.
- Simulação de processos de suporte técnico N1.

## ▶️ Como Executar o Projeto

### 1. Clone o repositório

```bash
git clone https://github.com/nicolaszborgesz-coder/HelpDesk-N1-Central-de-Suporte.git
```

### 2. Acesse a pasta do projeto

```bash
cd HelpDesk-N1-Central-de-Suporte
```

### 3. Execute a aplicação


Abra o endereço local informado pelo servidor ao iniciar a aplicação.
